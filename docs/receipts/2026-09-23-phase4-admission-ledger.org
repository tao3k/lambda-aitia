* Evidence and negative contracts

=assurance-host-admit= reads the Host-configured current snapshot and clock,
checks candidate evidence and an exactly bound successful outcome, executes
the configured POO Flow verifier, then issues a private-indexed POO admission.
It does not alter =AssuranceEvidence.admission-state= or the source snapshot.
Currentness rechecks the full semantic snapshot, Host epoch, verifier seal,
candidate evidence, outcome binding and lease.

=t/assurance/unit/evidence-admission-test.ss= checks that copied or fabricated
admissions fail; changed source, same displayed digest with changed semantic
content, invalid snapshot source, expiry, clock rollback, explicit revocation
and verifier refusal cannot provide current admission. A source cut returning
to an older value does not revive its earlier admission or Host seal.
