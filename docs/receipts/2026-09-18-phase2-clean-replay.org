* Toolchain boundary

POO Flow now detects whether the active =gsc= is the Homebrew Gambit runtime.
Only for that runtime, and only for each =just= child process, the build:

- removes =SDKROOT=;
- selects Apple clang through Gambit's documented =BUILD_*_CC_PARAM=
  parameters;
- suppresses the two GCC-option diagnostics emitted by Apple clang without
  replacing module-specific compiler options; and
- selects the native Darwin bundle linker contract through
  =BUILD_DYN_LD_OPTIONS_PARAM=.

No compiler wrapper is installed or maintained.  No shell profile, Homebrew
package, global Gerbil configuration, deployment target or parent environment
is changed.  If the active Gerbil runtime is not the Homebrew Cellar runtime,
including a Nix-provided Gerbil/Gambit toolchain, the boundary evaluates to
plain =env= and preserves the toolchain selected by Nix.
