* Summary

RFC 0026 formalizes the *Progressive Self-Teaching Loop* implemented across
=modules/gitops/review-flow.ss=, =bindings/commit-transport.ss=,
=rust/crates/aitia-runtime/src/commit/{defense_audit,formal_evidence,grpc_gateway,sidecar_cli}.rs=,
and the Marlin Agent Core gRPC harness (=aitia_grpc.rs=).

Its central thesis is that *progressive self-discovery and self-teaching is an
inference-time optimization targeting Large Language Models (LLMs) themselves —
not a human UX convenience*. Whereas human engineers build durable cross-session
mental models from static schemas and reference manuals, frozen-weight
Transformers operate over a stateless 1D token window subject to out-of-distribution
(OOD) DSL hallucination, U-shaped long-context attention decay, and lack of
internal symbolic verification.

By projecting a single zero-flag entrypoint (=aitia review= / gRPC
=StepReview= / tool =aitia_review_step=) that emits repo-bound grammars and
executable templates at the Turn 1 recency peak, validates Turn 2+ declarative
plans and ephemeral Quint 0.33 / Lean 4 overlays through deterministic kernels,
and unloads bulky templates (=compactChoices: true=) once aligned, =lambda-aitia=
dynamically specializes general-purpose fast models (e.g. =deepseek-flash=)
within 2--3 turns with *zero weight updates* and *zero system-prompt DSL
coaching*.

* Why This Optimizes the LLM Rather Than Human Users

Human engineers and autoregressive Transformers face opposite cognitive
bottlenecks:

| Dimension | Human Engineer | Frozen-Weight LLM (Inference Time) |
|-----------+----------------+------------------------------------|
| Memory substrate | Persistent long-term semantic & episodic memory across sessions | Stateless per session; private DSLs & subdomain packs are OOD in weights |
| Reference consumption | Random-access manuals, static JSON Schema, CLI =--help= | Flat 1D token stream; static megabyte manuals dilute Self-Attention |
| Error recovery | Reads source, asks peers, recalls prior bugs | Blind probabilistic resampling unless given structured verifier feedback |
| Optimization target | Lower human cognitive load & memorization | Maximize $P(y_{\text{valid}} \mid x_{\text{ctx}})$ in minimal turns & tokens |

Designing an agent tool as a 10-subcommand human CLI accompanied by a giant
static prompt manual optimizes for neither: humans already know their workflow,
while LLMs suffer schema hallucination, middle-context attention loss, and
multi-round thrashing.

* Human Schema Comprehension vs. LLM FunFlow Generation & Execution

1. *Abstract Schema Instantiation vs. Concrete Structural Conditioning*:
   - Humans read an abstract schema once, build a mental model of =PureCAS=
     prefixes, =open/closed= choice frontiers, and =FencedEffect= boundaries,
     and instantiate concrete configurations top-down.
   - Abstract schemas alone carry low semantic density for an LLM: knowing
     =planSexp: string= does not tell the model which clauses compose legally,
     which repo paths changed, or which of Deterministic Engineering's 37 Quint
     and 54 Lean SM17--SM37 models apply.
   - Emitting concrete, repo-bound executable scaffolds (=sexpPlanTemplate=,
     =quintOverlayTemplate=, =leanOverlayTemplate=) activates Transformer
     *induction heads*, turning zero-shot synthesis into high-probability
     *in-context structural editing*.

2. *Active Attention Filtering vs. U-Shaped Context Physics*:
   - Humans skip irrelevant chapters of a manual effortlessly.
   - LLMs exhibit a strong U-shaped primacy/recency attention curve; burying
     DSL rules and formal catalogs in the middle of a large system prompt
     severely degrades adherence.
   - Progressive disclosure exploits the *recency peak*:
     - *Before Turn 1*: zero DSL manual in the system prompt — only the concise
       =GetToolSchema= definition for =aitia_review_step=.
     - *Turn 1 response*: injects only the current repo's diff findings, compact
       =dslGrammar=, top 2--4 matched DE =recommendedFormalModels=, and
       repo-tailored executable templates immediately before Turn 2 decoding.
     - *Turn 2+ valid responses*: switches to =compactChoices: true=, unloading
       =dslGrammar=, all three templates, and =choices[*].template= so history
       stays high-signal and token-bounded.

3. *Internal Sanity Checking vs. External Deterministic Kernel Echo*:
   - Humans mentally detect cyclic =(depends-on a b) (depends-on b a)= edges,
     vacuous tests, or unproven =sorry= stubs before running tools.
   - Autoregressive left-to-right decoding has no built-in Datalog solver,
     model checker, or type-theory proof kernel.
   - FunFlow turns this into *inversion of control*: the LLM diverges freely
     inside bounded declarative payloads (zero-=eval= S-expr, strictly monotone
     POO =rule-pack=s, ephemeral Quint/Lean overlays), while deterministic
     kernels immediately compute exact verdicts and return actionable
     self-healing diagnostics.

* Peer-Reviewed Literature Foundations

The loop composes four distinct lines of established LLM systems and theory
research into one verifiable architecture:

1. *In-Context Learning Theory (Zero-Weight-Update Inference Optimization)*:
   - Xie et al., /An Explanation of In-context Learning as Implicit Bayesian
     Inference/, ICLR 2022: shows ICL acts as implicit Bayesian inference over
     latent document concepts $\theta$; Turn 1's coherent repo-bound grammar and
     templates collapse the posterior $P(\theta \mid x_{\text{Turn 1}})$ onto
     the target DSL manifold.
   - von Oswald et al., /Transformers Learn In-Context by Gradient Descent/,
     ICML 2023: demonstrates mechanistically that forward-pass self-attention
     implements implicit gradient descent (mesa-optimization) over in-context
     examples, explaining why Turn 1 concrete scaffolds and Turn 2 verifier
     diagnostics adapt the model without weight updates.

2. *Long-Context Attention Physics*:
   - Liu et al., /Lost in the Middle: How Language Models Use Long Contexts/,
     TACL 2024 (arXiv 2023): establishes the U-shaped primacy/recency retrieval
     curve, motivating zero static prompt manuals, Turn 1 recency-peak teaching
     injection, and Turn 2+ =compactChoices= unloading.

3. *Agent-Computer Interfaces (ACI), Schema Grounding & Composable Reasoning*:
   - Yang et al., /SWE-agent: Agent-Computer Interfaces Enable Automated
     Software Engineering/, NeurIPS 2024: introduces ACIs tailored specifically
     to LLM capabilities and failure modes rather than human terminals.
   - Patil et al., /Gorilla: Large Language Model Connected with Massive APIs/,
     2023: quantifies tool schema hallucination and demonstrates retrieval-bound
     interface grounding.
   - Wang et al., /Grammar Prompting for Domain-Specific Language Generation
     with Large Language Models/, NeurIPS 2023: shows pairing compact BNF
     grammars with concrete task-aligned examples enables reliable private DSL
     generation.
   - Zhou et al., /SELF-DISCOVER: Large Language Models Self-Compose Reasoning
     Structures/, Google DeepMind 2024: motivates letting LLMs *Select -> Adapt
     -> Implement* modular reasoning structures rather than hardcoding fixed
     workflows across thousands of subdomains.
   - Wang et al., /Executable Code Actions Elicit Better LLM Agents (CodeAct)/,
     ICML 2024: shows executable structured programs paired with live execution
     feedback outperform flat JSON tool calls by ~20%.

4. *Deterministic Verifier-Driven Verbal Reinforcement Learning*:
   - Shinn et al., /Reflexion: Language Agents with Verbal Reinforcement
     Learning/, NeurIPS 2023; Gou et al., /CRITIC: Large Language Models Can
     Self-Correct with Tool-Interactive Critiquing/, ICLR 2024: establish that
     reliable LLM self-correction requires *external deterministic verifiers*
     rather than pure self-reflection. =lambda-aitia= upgrades the critic from
     informal scripts to mathematically sound kernels (=gerbil-ascent=,
     =quint 0.33= MR05, =lean 4.36= kernel, Cedar, and Bi-Temporal Causality).
