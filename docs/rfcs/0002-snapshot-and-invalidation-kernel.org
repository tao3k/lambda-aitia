* Decision summary

An =AssuranceSnapshot= is an immutable, canonical fact cut binding graph,
source, claim, policy and evidence revisions.  A change produces an inert
=InvalidationReceipt= through pure traversal of typed relations.  The receipt
selects affected current obligations, evidence, decisions and effects; it does
not run a verifier, derive replacement obligations or authorize an effect.

* Input contracts

The initial kernel accepts:

- type-specific POO-native Artifact, Claim, Assumption, Observation, Event,
  Action, Obligation, Evidence, Counterexample, Finding, Decision and Effect;
- typed relations whose kind has exactly one relation-plane owner;
- graph identity, source and claim revision bindings, immutable fact cut,
  policy identity/revision and admitted evidence identities;
- a non-empty receipt identity and changed semantic identities.

Duplicate identities with unequal canonical content are conflicts.  Missing
relation endpoints and unknown change identities remain an unresolved frontier.

* Traversal contract

Structural and support relations are traversed from changed dependency target
to dependent source.  Authority effects are traversed from an impacted decision
to the effect target.  Temporal precedence is never promoted into causality and
does not participate in structural invalidation.

The current implementation projects the Aitia-owned relation directions into
POO Flow Graph values and delegates reachability, relation trajectories and SCC
analysis to the POO Flow structural-impact algorithms.  Aitia does not retain a
second traversal engine.  Dangling relations remain in the snapshot frontier
but are excluded from the executable Graph projection, so an incomplete
snapshot produces an inert receipt rather than an invalid Graph.

* Receipt contract

The receipt contains changed and impacted identities, invalidated evidence,
selected current obligations, invalidated decisions, blocked effects, witnesses
and unresolved inputs.  These fields are always false in this phase:

- =temporal-proven?=
- =release-authorized?=
- =runtime-executed?=

Phase 3 owns derivation of replacement obligations.  Phase 4 owns verifier
outcomes and evidence admission.  The Runtime Host owns effect execution.

* Required negative contracts

- a same-shaped non-nominal node is rejected;
- a cross-plane relation is rejected;
- hypothesized, counterfactual, stale or conflicted evidence cannot discharge
  an observed obligation;
- missing changed identities remain unresolved;
- a receipt cannot set temporal proof, release authority or runtime execution;
- input permutation cannot change snapshot or receipt identity order.

* Acceptance gates

- [X] Replace the local traversal with a minimal reviewed POO Flow Graph
  projection.
- [X] Add deterministic SCC and complete witness-path behavior.
- [X] Exercise monotone invalidation for the bounded fixed snapshot.
- [X] Reject stale or revision-mismatched evidence before obligation discharge.
- [X] Generalize the monotonicity law in the Aitia-owned formal proof package.
- [ ] Replay the bounded Software/SDLC change fixture from a clean checkout.
- [X] Retain exact source, policy and evidence revision receipts.

The RFC remains active until the clean-checkout replay closes.  The bounded
executable fixture validates the implementation, while
=LambdaAitiaProof.Modules.Assurance.Invalidation= independently proves the
general fixed-snapshot monotonicity law and the unresolved-frontier boundary.

The isolated candidate replay recorded by
=docs/receipts/2026-09-18-phase2-clean-candidate-replay.org= admits both the
Assurance fixture and the modular Lean gate at exact commits.  It does not close
the checkbox above: the full production build still depends on parent-owned
POO Flow User Interface, POO CLOS, Sources Lock and Standards library entries
that are not all present in the published parent revision.  Those mechanisms
must be published by POO Flow before Aitia can claim a clean-clone closure.

- ADR 0004 assigns the general laws and lifecycle models to Aitia.
- ADR 0005 defines persistence as a canonical non-authoritative projection.
