* CLI Surface & Local Installation

#+begin_example
aitia sidecar capture --repo <dir> [--base <ref>] --profile <file> [--checks <file>]
aitia sidecar assess < assessment-request.json
aitia sidecar verify-formal --context-digest <sha256:...> < formal-evidence.json
aitia sidecar receipt [--repo <dir>] [--vault-dir <dir>] < receipt-spec.json
aitia sidecar commit --repo <dir> --vault-dir <dir> < receipt-spec.json
#+end_example

=aitia sidecar commit= works directly in pure Git repositories and pure Git
*worktrees* (where =.git= is a file, with zero =.jj= and zero =.agents/aita/=):
it verifies =vault-outside-repo=, verifies HEAD matches audited =baseCommit=,
verifies pre-staged paths contain zero forbidden prefixes, seals and archives
the NASA Org report + DSSE bundle into =--vault-dir=, and commits only the
pre-staged index with the verified clean upstream headline.

=just install-local= builds and installs the release Rust =aitia= binary into
=~/.local/bin/aitia=, verifying zero-=GERBIL_LOADPATH= operation from =/tmp=
so external Git/worktree repositories invoke =aitia sidecar ...= directly
from =$PATH= with zero Python dependency and zero manual symlinks.

1. *Zero Upstream Pollution & Vault-Outside-Repo Confinement*: When
   =--vault-dir= is passed to =aitia sidecar receipt=, the runtime canonicalizes
   both the vault directory and the external repository root and refuses
   fail-closed if the vault path resolves inside the external repository tree.
2. *Single-Binary Zero-=GERBIL_LOADPATH= Execution*: Native LLM hosts (IDE /
   Chat Agents / Skills / CI workflows) invoke =aitia sidecar ...= directly
   with no Python runtime or Scheme loadpath required.

   =upstream-library-reuse= (pinned DE Quint/Lean libraries) and project-specific
   =ephemeral-ai-overlay= (mandatory =MR05= =@countermodel= + Sidecar Vault
   isolation).
