* Decision and present boundary

Lambda Aitia owns Software Engineering Profile values and the maintained
=aitia= Case. POO Flow owns semantic Module identities, Profile exports,
=use-module=, =compose profiles=, =user-composition=, Case lowering, admission
and Session behavior. The ordinary value is POO-native; Aitia does not own a
parallel selector, catalog, graph or runtime.

POO Flow's current public expression surface is:

#+begin_src scheme
(user-composition project
  (compose profiles
    (use-module AitiaModule default)))
#+end_src

The maintained Aitia owner provides =AitiaModule= and its already composed
=aitia= value in =user-interface/compositions/aitia.ss=. The default Project
declares GitOps, SDLC, NASA, ADR/RFC, assurance and formal-method selections.
Declaration alone neither executes a verifier nor establishes compliance or
release authority.

The former =(use-composition aitia)=, implicit catalog and single-expression
file loader were removed from POO Flow's public surface by its native Profile
algebra migration. Their earlier tests no longer qualify the current API.
The no-import, one-expression downstream convenience requested for ordinary
users remains open. Aitia will not recreate the removed loader locally or
present an untested downstream snippet as supported.

* Namespace and edition

The canonical NASA standard-family identity is =nasa/sdlc/npr-7150.2=:
organization =nasa=, domain Module =sdlc=, Profile =npr-7150.2=. The selected
standard object explicitly carries =edition: D=, effective date and source
URLs. Its versioned Source Lock uses exact edition, source digests and byte
counts. A future edition changes the bound source and assessment evidence,
not the public family namespace or Scheme/Python import path.

The maintained GitOps Scenario selects this typed Module Profile with:

#+begin_src scheme
(use-module NasaSdlcModule npr-7150.2)
#+end_src

Its check name is a workflow gate keyed to the standard family. A green
check with only that name now fails closed: the check must also match the
selected Standard object's edition and Source Lock digest. These check
fields are still caller-supplied workflow data, not an Assurance seal or
proof of actual verifier inputs. Accountable Host admission and source-byte
binding remain separate acceptance gates.

* Composition semantics

The default path composes maintained POO Profile values; advanced users may
extend those values with ordinary POO slot operations before composition.
Profile selection preserves Module definition, instance, Profile identity,
revision and generation in POO Flow selection proofs. The resulting Case owns
one execution-plan projection and fresh Sessions. Importing or composing
values has no Runtime effect.

The official =aitia= Case is a maintained object graph, not an empty template.
Its Project Profile declares Software Engineering responsibilities and
selection of GitOps, SDLC, NASA, ADR/RFC, assurance and formal-method
obligations. The Project declaration does not yet prove that all downstream
slots, verifier bindings and no-import UX are complete.

* Ownership and trust

| Owner | Responsibility |
|-------+----------------|
| Aitia | Software Engineering/NASA semantics, maintained Profiles and Case, qualification scenarios |
| POO Flow | Module/Profile algebra, composition, Graph, Case admission, Session and Runtime handoff |
| Application Host | source reads, verifier execution, authority and effects |

The Python project under =bindings/python= consumes Aitia's native C ABI; it
does not parse a second configuration model or recreate SDLC semantics.
Versioned NASA source identities are provenance facts, not namespace segments
that ordinary users must type.

* Acceptance gates

- [X] Official Aitia and NASA identities lower through POO Flow's public
  =user-composition=, =use-module= and Profile algebra.
- [X] The maintained Aitia Case and GitOps/NASA Scenario construct without
  Runtime execution and have focused tests.
- [ ] A zero-override downstream file can select =aitia= without imports or
  exposing POO internals, through a POO Flow-owned public mechanism.
- [ ] An advanced override extends the same maintained Project Profile and
  preserves selection/provenance receipts.
- [X] The pure GitOps decision rejects a same-name green check lacking the
  selected edition or Source Lock digest, including a check for another edition.
- [ ] A Host-issued NASA assessment binds actual verifier inputs, source bytes,
  exact edition and Source Lock digest before it can count as Assurance support.
- [ ] Case, C ABI and Python project consume one canonical composition cut in
  a clean checkout across both repositories.
- [ ] Source-located diagnostics, doctor presentation and scale receipts pass
  for the current POO-native expression path.
