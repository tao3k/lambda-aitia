* Context and Problem Statement

The assurance laws and lifecycle model need one source owner.  POO Flow already
contains generic composition and runtime proofs, but those artifacts must not
become owners of Aitia claim, evidence or invalidation semantics.

* Decision Outcome

Lambda Aitia owns Lean statements and TLA+ models whose vocabulary is defined by
Aitia, including evidence freshness, no stale authority, invalidation,
counterfactual isolation and the assurance lifecycle.  It may consume a pinned,
independently versioned POO Flow proof package for generic composition laws.
POO Flow proof sources are referenced, not copied or silently moved.

Theorems and TLC receipts remain evidence inputs.  Neither grants a current
Decision or Effect authority.

* Consequences

- Good: proof statements evolve with their semantic owner.
- Good: generic POO Flow laws remain reusable and independently released.
- Bad: cross-repository theorem dependencies require explicit version receipts.

* Confirmation

- Aitia proof builds run from Aitia-owned source paths.
- Imported POO Flow theorems name an exact package revision.
- Negative fixtures show that a theorem or TLC success is not runtime authority.
