* First bounded transfer judgment

The current job-executor shares the first source's response-loss uncertainty
and logical retry identity question. It differs in workload and provider: one
fixed job, constant payload, local SQLite and a loopback HTTP endpoint. It has
no multi-tenant identity, retention policy or independently committed remote
side effect. Those differences prevent a claim that it implements the source's
complete service contract.

The source motivates questions; source inspection answers what the fixture
currently models. [[file:../adrs/0008-stable-operation-key-after-lost-ack.org][ADR 0008]] assigns pending checks to their actual owners,
including existing Cedar authorization and Runtime handoff mechanisms. The
judgment is provisional: provider changes, conflicting observations or source
corrections reopen it. A future executable assessment must bind the consulted
source revision and affected ADR/claim identities before testing invalidation.
