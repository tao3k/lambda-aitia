#+title: Contributing to Lambda Aitia

* License

Every contribution is accepted under =Apache-2.0 AND
LGPL-2.1-or-later=.  Source files must carry the repository SPDX header unless
their format is covered by =REUSE.toml=.

* Ownership boundaries

- Lambda Aitia owns Software/SDLC, NASA, GitOps, assurance semantics and its
  own C and Python bindings.
- Lambda Episteme owns non-SDLC vertical knowledge such as Healthcare.
- Agentic AI Lab owns POO/functional composition, graph substrate and generic
  runtime handoff.  Agentic AI Lab core must never import Lambda Aitia.
- Public extension APIs are ordinary POO-native objects and named pure
  functions.  Raw alist DSLs and anonymous compute hooks are not public APIs.

* Change acceptance

A change is not complete from a happy-path result alone.  It must include the
source owner, negative contracts, focused tests, affected public-consumer tests
and an attributable receipt.  A plan, proof, authorization and executed effect
remain separate facts.

Run the relevant repository gates from the Agentic AI Lab mount:

#+begin_src sh
just build-contribute lambda-aitia
just test-contribute lambda-aitia modules
just test-contribute lambda-aitia assurance
just check-aitia-native
just check-license-contract
#+end_src

Do not add compatibility aliases, version suffixes to the public Scheme or
Python namespace, or duplicate Aitia semantics in Python.

* Native compiler products and dependency completion

Keep generated =.ssi=, =.ssxi.ss=, numbered dynamic objects and
=.gxc-complete= files outside Git. Authored =.scm= test fixtures remain source.
A package directory or generated interface does not establish a completed
runtime or macro-phase family.

The Scheme workflow requests ASCENT's actual =build.ss spec= and passes its
library declarations, with their original options, to native =std/make=.
Existing Core =repair-build-products!= invalidates interrupted units and
=require-build-products!= checks completion. Executable delivery remains a
separate demand; this library repair issues no package publication receipt.
See [[file:scripts/check-native-products.ss][the native completion entry]] and
[[file:t/native-products-test.ss][the real-product negative controls]].

Preserve the test runner's returned status explicitly when invoking its Scheme
API: a printed failure with an ignored return value must not become success.
All added native checks and library repairs use the 2 GiB heap and 180-second
process deadline. A failed install resource receipt cannot be replaced by a
successful directory-existence probe or saved as admitted dependency output.

Aitia's native ASP requirement is built through the SDK's public =pkg-update=
and =pkg-build= operations, with its revision read from =gerbil.pkg=.
The real native manifest and original build entry remain required. CI does
not request the global editor =gxtags= index: indexing every acquired source
checkout is a separate developer demand, not a compiler or runtime receipt.
