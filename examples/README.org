#+TITLE: Lambda Aitia Executable SDLC & GitOps Examples

Every example here executes against the pre-compiled standalone Rust =aitia= binary and/or the
pre-compiled =liblambda_aitia_rust.{so,dylib}= =cdylib= with *zero =GERBIL_LOADPATH=* and
*zero downstream Gerbil/Gambit compilation*.

All workflow topology, SDLC profile composition, and 5-state IoC semantics live strictly inside
SysML v2 and Scheme POO/ASCENT/FunFlow.

* Flagship End-to-End SDLC Cases

- [[file:cardano-diamond-release-train/README.org][=cardano-diamond-release-train/=]] (*IOHK/Bazel 4-Repo Diamond Release Train*, RFC 0009):
  Real 4-repository diamond (=protocol-base -> {ledger-core, network-mux} -> node-runner=) across
  4 real JJ workspaces, 4 bare Git remotes, and one SysML v2 =workspace.sysml=:
  1. Bazel Skyframe Early Cutoff (upstream commit advances with unchanged =interfaceDigest= ->
     downstream pruned via =earlyCutoffs=, zero spurious repair);
  2. Bazel Bzlmod / IOHK CHaP Diamond Conflict (Wave 1 peers disagree on =protocol-base= ABI ->
     fail-closed =need-human-decision= /=diamond-pin-conflict=/ at =node-runner=);
  3. 3-wave cascading fenced commit & bare-remote push across all 4 repos with verified
     =repoEvidenceLineages= (=missingReports: []=).
- [[file:sdlc-release-train/README.org][=sdlc-release-train/=]] (*Billing Core -> Checkout Service Release Train*):
  Complete 4-stage real engineering release train across two real JJ repositories, two bare Git
  remotes, and an authoritative SysML v2 =workspace.sysml= topology:
  1. Architecture & =open-security= design gate (competing hypotheses preserved -> resolved);
  2. Implementation cut + =aitia flow run --workspace workspace.sysml= detecting
     =cross-repo-pin-drift= against real commit SHAs;
  3. Reviewed commit drafts (=aitia jj commit= + =preview=) before human approval;
  4. Cascading Wave 0 -> Wave 1 fenced commit & bare-remote push
     (=aitia flow submit-decision --workspace workspace.sysml --execute-fenced=) with per-repo
     verified =repoEvidenceLineages= (=missingReports: []=).
