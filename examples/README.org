#+TITLE: Lambda Aitia Executable Examples by Use Case

Every example in this directory runs against the pre-compiled standalone Rust =aitia= binary
and/or the pre-compiled =liblambda_aitia_rust.{so,dylib}= =cdylib= with *zero =GERBIL_LOADPATH=*
and *zero downstream Gerbil/Gambit compilation*.

All workflow topology, SDLC profile composition, and 5-state IoC semantics remain 100% inside
Scheme POO/ASCENT/FunFlow and SysML v2. Python is used here strictly as:
- a thin in-process ABI caller (=lambda_aitia_rust.Session= or pure =ctypes= C ABI) to avoid CLI
  cold-start overhead in multi-turn loops, or
- a leaf verification target invoked by FunFlow (=python.observe-pytest=).
